# Ghi chú theo tuần

Tạo file `week-01.md`, `week-02.md`, ... bằng cách sao chép [mẫu ghi chú](../templates/weekly-note.md). Mỗi file nên lưu mục tiêu, tài liệu đã học, đầu ra, lỗi đã xử lý và checkpoint đạt được.

Giữ ghi chú tập trung vào những gì bạn tự làm và hiểu được; có thể thêm link tới notebook, SQL, commit hoặc project tương ứng.
